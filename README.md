# Master in Italian Food Design - Landing Page

Landing page ufficiale del Master di II Livello in Italian Food Design.

## 🎨 Caratteristiche

- Design minimalista in stile Italian Food Design
- Fotografia professionale integrata
- Riquadri grigi con sovrapposizioni artistiche
- Caroselli interattivi per esplorare i moduli
- Completamente responsive
- 76 CFU distribuiti in 6 aree formative

## 🚀 Deploy su Vercel

### Deploy con un click

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/TUO-USERNAME/master-ifd-website)

### Deploy manuale

1. Fai il fork di questo repository
2. Vai su [vercel.com](https://vercel.com)
3. Clicca su "New Project"
4. Importa il repository GitHub
5. Clicca su "Deploy"

## 📦 Installazione Locale

```bash
# Clona il repository
git clone https://github.com/TUO-USERNAME/master-ifd-website.git

# Entra nella cartella
cd master-ifd-website

# Apri con un server locale (opzionale)
python -m http.server 8000
# oppure
npx serve
```

Poi apri http://localhost:8000 nel browser
